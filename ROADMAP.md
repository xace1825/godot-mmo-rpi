# Fantasy Settlement MMO — Roadmap

Цель: persistent-world settlement builder в духе **Songs of Syx × RimWorld × Project Rebearth**, с возможностью военных действий на поздних этапах.

---

## Этап 0. Стабилизация (ГОТОВО)

Готовность: Windows-клиент подключается и работает без явных багов.

- [x] Сервер на RPi / Windows headless, UDP 7777
- [x] Авто-реконнект клиента
- [x] Ресурсы стартуют на складе
- [x] Ручной спавн жителей через SPAWN
- [x] Сброс мира через RESET
- [x] Лут виден на клетках (ground items)
- [x] Инфо-панели для складов и жителей
- [x] Pathfinding: greedy step + anti-backtracking
- [x] Камера и UI без сквозных кликов
- [x] Автосохранение и автозапуск сервера
- [x] Main menu + режимы singleplayer/host/client

Ключевые файлы: `main.gd`, `build_ui.gd`, `network.gd`, `game_state.gd`, `main_menu.gd`, `game_launch.gd`

---

## Этап 1. Playable Core (ГОТОВО)

Готовность: первые 10 минут игры понятны и веселы.

- [x] Профессии: дровосек, каменщик, фермер, строитель, повар, столяр, каменщик, носильщик
- [x] Производственные цепочки: дерево → доски, камень → блоки, еда → готовая еда
- [x] Жители переносят ресурсы в склад
- [x] Стены / полы / двери через drag-to-build
- [x] Базовые нужды: голод, энергия, комфорт
- [x] Сохранение/загрузка мира
- [x] Визуально читаемая карта и UI
- [x] Синхронизация villagers каждые 0.2 сек
- [x] Ручное назначение профессий
- [x] Production stations walkable

Ключевые файлы: `job_manager.gd`, `game_state.gd`, `planet_generator.gd`, `build_ui.gd`, `villager.gd`

## Этап 2. Settlement Identity — Songs of Syx / RimWorld feel

Готовность: игра ощущается как полноценный settlement builder.

### 2.1 Комнаты и комфорт
- [ ] Indoor room stats (RimWorld-style)
- [ ] Кровати, двери, стены влияют на комфорт и качество сна
- [ ] Wealth, beauty, space, cleanliness бонусы
- [ ] Mood / needs расширенный

### 2.2 Расширенное производство
- [ ] Кузница (SMITHY) + профессия кузнец
- [ ] Инструменты: ресурс `tools`, влияют на скорость работы
- [ ] Износ инструментов и ремонт
- [ ] Больше станций: печь, ткацкий станок, пивоварня

### 2.3 Quality of Life
- [ ] Приоритеты работ (job priorities UI)
- [ ] Зоны: роста, свалки, запретные зоны
- [ ] Отмена/приоритет чертежей
- [ ] Расширенные инфо-панели: продуктивность, настроение, здоровье

### 2.4 Мир и разведка
- [ ] Глобальная карта мира (не 1:1 Earth, но масштабная)
- [ ] Биомы: лес, тайга, пустыня, болото, горы, океан
- [ ] Биом влияет на ресурсы, скорость фермерства, строительные материалы
- [ ] Выбор стартовой локации с учётом биома
- [ ] Разведка окрестностей (fog of war expansion)

Ключевые файлы: `game_state.gd`, `job_manager.gd`, `planet_generator.gd`, `build_ui.gd`, `info_panel.gd`

## Этап 3. World & MMO — Project Rebearth direction

Готовность: несколько игроков в одном persistent мире, торговля, исследование.

### 3.1 Persistent shared world
- [ ] Мир живёт, пока игроки офлайн (симуляция offline-времени)
- [ ] Игроки выбирают точку старта на глобальной карте
- [ ] Минимальная дистанция между базами
- [ ] Глобальная карта с городами других игроков

### 3.2 Социальная и экономическая активность
- [ ] Торговля между игроками: предложения, караваны
- [ ] Общий рынок / обмен ресурсами
- [ ] Чат, координаты на карте
- [ ] Визит к другому игроку (переключение камеры на его базу)

### 3.3 Экспедиции и история
- [ ] Отправка экспедиций в мире
- [ ] Реальное время ожидания (как в Project Rebearth)
- [ ] Артефакты и обрывки лора
- [ ] Технологии / lost knowledge
- [ ] PvE события: погода, болезни, дикие звери

### 3.4 MMO инфраструктура
- [ ] Сервер сохраняет мир между сессиями
- [ ] Авторитет сервера на всём состоянии
- [ ] Оптимизация sync для большого числа игроков
- [ ] Anti-cheat basics

Ключевые файлы: `network.gd`, `game_state.gd`, `player_manager.gd`, новый `expedition_manager.gd`, новый `trade_manager.gd`

## Конвенции проекта

- `TILE_SIZE = 32`, пиксель-арт 32×32
- Авторитет сервера на всем состоянии
- Ручной спавн жителей через SPAWN
- `Engine.time_scale = 1.0`
- Все ресурсы живут на складах, не в глобальном пуле
- Pathfinding: greedy step + anti-backtracking
- Watchdog cron job перезапускает сервер каждые 2 минуты при падении
